MOVIDOC TicTrack project

-------------------
Analyse des pilotes
-------------------
01_Movidoc_tictrack_prepro.ipynb = Jupyter Notebook file to analyse the .vhdr file of 1 pilote at a time (load the data, filter the signals, re-reference the signals, reset (cut) the files, extract phases 1, 2 & 3, and create epochs)
01_Movidoc_tictrack_prepro.py = Python file to analyse, with a loop, the .vhdr files of all the pilotes (load the data, filter the signals, re-reference the signals, reset (cut) the files, extract phases 1, 2 & 3, and create epochs)


--------------------
Analyse des patients
--------------------
02_Movidoc_tictrack_prepro-patients.ipynb = Jupyter Notbook to analyse the .vhdr file of 1 patient at a time (load the data, filter the signals, re-reference the signals, and reset (cut) the files)
02_Movidoc_tictrack_prepro-patients.py = Python file to analyse, with a loop, the .vhdr files off all the patients (load the data, filter the signals, re-reference the signals, and reset (cut) the files)
